Asked by the user (2026-09-01). Build on the existing same-God cluster, especially [[the-same-god-question-turns-on-reference-versus-description--202608311942]]: Anselm's 'that than which nothing greater can be conceived' functions as a reference-fixing description, which bears directly on the reference-vs-description crux.

**Answer (2026-09-01):** Three things can be inferred, one per result note.
(1) The argument identifies God by a bare description graspable even by the
unbelieving fool, so it supplies a tradition-neutral way of aiming at God;
Anselm's own "and this being you are, O Lord, our God" is a further step the
proof does not perform. (2) The description admits at most one bearer, so
insofar as worshippers target whatever satisfies it, doctrinal disagreement
cannot split the referent -- the Anselmian/classical-theist co-reference
argument Beckwith made during the Wheaton dispute. (3) The inference is
conditional on the description actually doing the referring: on
dossier-dominance semantics (Bogardus & Urban) revelation-specific information
may dominate the divine names, and worship may require more than reference --
so the ontological argument yields a conditional, not a verdict. Grounded in a
verbatim capture of Proslogion Preface + chs. 1-5 (Deane trans.), both
Beckwith columns in full, and the Bogardus & Urban abstract (full text
inaccessible from this environment; see INBOX).
