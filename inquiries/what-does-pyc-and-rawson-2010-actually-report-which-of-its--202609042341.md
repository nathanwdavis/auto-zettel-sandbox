What does Pyc and Rawson (2010) actually report, which of its results did the SSRP replicate, and does that replication reach any claim this base makes about retrieval practice?

---

## Answered by the 2026-09-04 cycle — the second of the two SSRP papers gap note 202609041920 named

Filed to close the standing half of gap note
[[the-retrieval-practice-programme-has-a-preregistered-replication-and-this-base-has-not-read-it--202609041920]],
which had already been resolved for Karpicke & Blunt (2011) and left open for Pyc
& Rawson (2010).

**Identification, verified before it was relied on.** Crossref, PubMed (PMID
20947756) and Semantic Scholar all return the same record — Pyc, M. A., and
Rawson, K. A., "Why Testing Improves Memory: Mediator Effectiveness Hypothesis,"
*Science* 330(6002):335 (2010), DOI 10.1126/science.1191465 — and the SSRP's own
OSF repository carries a component literally titled "Replication of Pyc and
Rawson (2010)" (`osf.io/dvgan`, study 31 of the twenty-one), which confirms the
identity at the host. It is this base's Katherine A. Rawson in the
retrieval-practice literature, not the note-taking one, so the surname
coincidence the gap note refused to resolve is resolved from the source.

**What the paper reports.** It proposes the *mediator effectiveness hypothesis*:
test-restudy practice improves later memory because it produces better mediators
— the cue-to-target links a learner forms — where a good mediator must both be
retrievable at test and elicit the target once retrieved. Test-restudy produced
mediators stronger on both counts than restudy alone. Written up as
[[the-testing-effect-works-by-producing-more-retrievable-target-eliciting-mediators--202609042340]].
(The full text was paywalled; this rests on the paper's authoritative abstract,
with the design corroborated by the replication report — recorded honestly in the
reference note.)

**Which result the SSRP tested, and its outcome.** By the first-significant-effect
rule the project tested one comparison — mediator recall, test-restudy versus
restudy-only, in the cue-mediator-target final-test format (original n = 36,
`t(34) = 2.37`, `p = 0.0236`). It did *not* replicate at the first data
collection (n = 132, `p = 0.0893`) and crossed significance only in the pooled
second-stage sample (n = 306, `p = 0.0087`; one-sided default `BF+0 = 6.8`).
Written up as
[[the-one-pyc-and-rawson-result-the-ssrp-tested-replicated-only-after-the-second-stage-sample--202609042345]].

**Does it reach any claim this base makes? Yes, but weakly, and the caution
held.** It is genuine independent support for the retrieval-over-restudy claim,
and the mechanism note is a real addition to the cluster — but the SSRP tested
one cell of a six-cell design, that cell needed the larger sample to replicate at
all, and what replicated was mediator recall, not the mechanism. So it promotes
one result, not the paper or the programme, exactly as
[[a-replication-project-that-tests-one-study-per-paper-cannot-settle-the-paper--202609041905]]
requires. Gap note 202609041920 is now fully resolved for both papers.
