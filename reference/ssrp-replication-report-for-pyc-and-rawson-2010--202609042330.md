Bibliographic record. The Social Sciences Replication Project's per-study
replication report for Pyc & Rawson (2010), authored by Colin Camerer, Taisuke
Imai, Dylan Manfredi and Gideon Nave. As with the project's Karpicke & Blunt
report ([[ssrp-replication-report-for-karpicke-and-blunt-2011--202609042135]]),
this is a **distinct source** from the project's summary Letter in *Nature Human
Behaviour* ([[camerer-et-al-evaluating-the-replicability-of-social-science-experiments--202609041855]]):
the Letter reports the aggregate across all 21 studies and prints no per-study
statistics, while this report states which Pyc & Rawson result was targeted and
the numbers behind its two-stage replication. It is the evidence the summary
summarises.

**Reached through the OSF API**, the route this base first walked for the
Karpicke & Blunt report: SSRP root node `pfdyw` → the component literally titled
"Replication of Pyc and Rawson (2010)" (`osf.io/dvgan`) → its "Replication
Reports" sub-component (`osf.io/tn4x9`) → the final report PDF
(`osf.io/download/zj5n3/`, file created 2018-08-16). The existence of a
component so titled among exactly twenty-one sibling replications confirms, at
the host, that the "Pyc and Rawson (2010)" the SSRP tested is this paper — the
identification the standing half of gap note 202609041920 asked for, made at the
project's own repository rather than from a surname and a year.

**License and capture.** The `dvgan` node carries CC0 1.0 Universal (public
domain), confirmed via the OSF API. Because it is CC0, the four-page report is
captured in full in `raw/` rather than as an excerpt, with the PDF's SHA-256
(`7c9eca93…febcca8`); the downloaded file is 90,294 bytes, matching the size the
OSF file listing reports.
