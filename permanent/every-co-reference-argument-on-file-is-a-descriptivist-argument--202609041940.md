Sort this repository's arguments *for* co-reference by the taxonomy in
[[michaelson-sets-out-four-models-of-reference-fixing-and-declines-to-make-them-exclusive--202609041926]],
and they all land in one box.

- Nostra Aetate's ground is a description: Muslims "adore the one God, living
  and subsisting in Himself... the Creator of heaven and earth" (see
  [[the-same-god-question-turns-on-reference-versus-description--202608311942]]).
- The Anselmian route is explicitly descriptive — maximal greatness has at most
  one bearer, so anyone who worships under that description co-refers (see
  [[maximal-greatness-has-at-most-one-bearer-so-perfect-being-worshippers-co-refer--202609010841]]).
- Beckwith locates co-reference in general revelation, which is a shared *route
  to a description* of the same being (see
  [[beckwith-locates-co-reference-in-general-revelation--202609010837]]).
- al-Tabari's gloss identifies a shared *ma'bud*, an object under a description
  (see [[the-foundational-tafsir-glosses-the-shared-god-clause-as-a-shared-object-of-worship--202609040710]]).
- Even the one properly semantic treatment on file, Evans's dossier dominance in
  Bogardus and Urban, decides by weighing *information in the dossiers* — which
  is a descriptivist criterion, refined, not abandoned (see
  [[bogardus-and-urban-make-co-reference-turn-on-dossier-dominance--202609010838]]).

Not one argument in the base runs the other way: none argues that the traditions
co-refer because their uses of the name descend by transmission from one
original act of naming, whatever anyone since has believed about the bearer.
That is the causal model's argument, and it is absent.

The absence is easy to miss because "reference" is the word both sides use.
Arguing that two communities refer to the same being *because they describe him
alike* is not the alternative to descriptivism; it is descriptivism, making a
claim about reference. So the dispute this base has documented at length is, on
the semantics literature's own map, a family quarrel inside one of four
positions — and the position that would most cleanly deliver "same God" has
never been put.
