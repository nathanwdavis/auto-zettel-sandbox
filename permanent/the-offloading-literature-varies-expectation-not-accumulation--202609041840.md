This repository went looking for experimental work on externalised memory
because the note-taking experiments turned out to be about handwriting rather
than about notes
([[the-note-taking-experiments-do-not-reach-the-slip-box-claims--202609040215]]).
The offloading literature is genuinely about externalised memory. It still does
not reach the claims a slip box makes, and the reason is structural rather than
accidental: the variable it manipulates is a *belief about retrievability*, held
for minutes, over material that has no relations in it.

Take the strongest case. Forty trivia statements; the manipulation is a message
saying the typing was saved or erased; the measurement is free recall in the
same session
([[expecting-a-saved-copy-cost-nine-points-of-recall-in-the-same-session--202609041825]]).
Three things a slip box asserts are absent from that design, and absent by
construction rather than by oversight.

**No accumulation.** Forty items, seen once. The claim under test in this
repository is that a store's value is not linear in its size — that it does
nothing much for a long time and then starts producing what its owner did not
put in ([[a-slip-box-surprises-only-after-critical-mass--202609010113]]). A
forty-item store cannot exhibit or fail to exhibit that; there is no time axis
on which it could.

**No linking.** The statements are unrelated by design — an ostrich's eye, the
Columbia disintegration — and nothing in the procedure lets one bear on
another. The proposition that externalising *connections* differs from
externalising *facts* is the whole content of the method, and this design
cannot see the difference, because it contains only facts.

**No delay.** Everything is measured in the session in which it was learned.
The measurement in this repository closest to it that did let a week pass found
an advantage worth sixteen points collapse to nothing
([[having-the-notes-to-hand-buys-present-performance-not-durable-knowledge--202609040345]]),
which is reason enough to treat a same-session number as a fact about the
session.

State the resulting gap precisely, because a vague version of it would be a
false absence rather than a finding. Of the experimental sources this
repository has read on memory and external storage — the retrieval-practice
cluster captured on 2026-09-04 and this one — not one manipulates *how much* is
stored, and not one manipulates whether the stored items are *related to each
other*. That is a claim about designs this repository has actually read, checked
against each of them, and it is deliberately not the claim that no such study
exists. It is what the 2026-09-04 inquiry asked to be established one way or the
other, and this is the result: the missing study is still missing, and it is now
missing from the literature that was the last plausible place to look rather
than from a literature that was never about the subject.

What follows for the method is not scepticism but relocation. A slip box's
claims are about a store that grows, whose items point at each other, and whose
payoff arrives in years. No experiment has tested that, and none of the ones
here comes close enough that its null or its effect can be borrowed. So the
warrant for the method remains what it has been in this repository from the
start — argument, and the testimony of people who ran one
([[luhmann-frames-the-slip-box-as-a-communication-partner--202609010112]]) — and the honest
addition from this cycle is that the experimental literature has now been
looked at properly and does not supply more.
