Over long horizons the number of compounding periods matters more than the rate per period, because periods multiply while the rate only scales each step.

**2026-09-03: grounded.** This note was one of six genesis fixtures carrying no
source link at all, and the 2026-09-03 graph walk found that it is not a leaf
-- it ranks joint-fourth in the repository by in-degree, so grounded notes were
leaning on an ungrounded one. The source was already in the repository and

do better as an investor, the single most powerful thing you can do is increase
your time horizon" (see
[[housel-on-compounding-as-time-in-the-loop--202608311037]], ch. 4).

Two limits on what that link establishes. Housel's claim is about *investing*,
where the rate is not freely choosable and the horizon partly is; the sentence
above is a claim about the arithmetic of compounding as such, which is wider
than his evidence, and this note's own reason for it -- that periods multiply
while the rate only scales each step -- is a mathematical argument that Housel
does not make. And the grounding behind the Housel note is a cross-checked
excerpt rather than the full chapter, which the note itself records. So this is
a real source for the claim's substance, not a demonstration of it.
