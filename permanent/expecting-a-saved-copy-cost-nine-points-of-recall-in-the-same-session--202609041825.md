Believing that a machine has kept a copy of something lowers how much of it you
can produce from memory afterwards. In the one experiment this repository has
found that isolates the belief and nothing else, the cost was nine points of
recall — 0.31 in the erased conditions against 0.22 in the saved ones, with the
instruction to try to remember making no difference at all
([[sparrow-liu-and-wegner-ran-one-priming-experiment-and-three-offloading-ones--202609041810]]).

The design is what makes this worth a note. Everyone read the same forty
statements and typed each one in. The only thing that varied was what the
participant was told happened next. Nobody wrote differently, nobody attended
differently by instruction, nobody had different material. So the difference
cannot be attributed to the medium of writing, which is the confound that
defeated the note-taking literature
([[the-note-taking-experiments-do-not-reach-the-slip-box-claims--202609040215]]).
It is attributable to the *expectation of retrievability*, which is exactly the
variable a slip box manipulates and the one this repository had never seen
measured.

This is the first direct measurement here of the cost side of externalising.
Until now the repository's account of why the note became an external memory
ran through a historian: Chavigny's judgement that "too much memorizing can be
harmful to the higher intellectual qualities", argued and not measured
([[the-note-became-an-external-memory-only-when-memorizing-came-to-be-seen-as-a-cost--202609032115]]).
That note is now `supports`-linked from here, and the support is real but
narrow: what the experiment vindicates is the *premise* that offloading changes
what stays in the head, not the *evaluation* that the change is a gain.
Chavigny's whole claim is that the trade is worth making. Nothing here measures
the other side of it.

Three limits, and the third is the one that keeps this note from doing more
work than it can. **The material is forty unconnected trivia statements**, so
nothing about accumulation or linking is in the design. **The measurement is
taken in the same session**, so this is a fact about immediate recall and not
about knowledge — which is the same boundary
[[having-the-notes-to-hand-buys-present-performance-not-durable-knowledge--202609040345]]
draws from the other direction, where an open-book advantage worth sixteen
points immediately was worth nothing a week later. The two notes are
`shared-concept` and not one supporting the other, because they measure
opposite arrangements: one has the notes present at test, the other has them
absent but expected to exist. **And the result is unreplicated**, from a paper
whose reporting did not survive an audit
([[the-google-effects-replication-record-reaches-only-its-priming-experiment--202609041820]]).
Sixty participants and an omnibus `F(3, 56) = 2.80` scraping under `P < 0.05`.
On the unreplicated part, be exact about what was checked rather than
implying a survey: the 2020 paper that reviews this literature in order to
replicate its companion experiment records no replication of this one, and a
search for one found none. That is two negative checks, not an established
absence, and a run that turns up a replication should expect to be adding to
this note rather than contradicting it.

So the honest statement of what this repository now holds is: there is one
small, unreplicated, same-session measurement of the cost of expecting external
storage, and it is nine points of recall on trivia. That is a great deal more
than the repository had yesterday, when it had an argument from a historian.
It is not enough to build on, and a note that cited it as though offloading's
cost were settled would be repeating the mistake this repository has now
documented twice in this literature.
