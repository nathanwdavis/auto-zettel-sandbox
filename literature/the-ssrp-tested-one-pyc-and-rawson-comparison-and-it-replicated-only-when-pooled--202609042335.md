Summary of
[[ssrp-replication-report-for-pyc-and-rawson-2010--202609042330]] in my own
words; the verbatim numbers live in the raw capture and this note reports the
report's design and outcomes.

**Which result was tested.** The SSRP's rule takes the first significant
treatment effect in a paper. Pyc & Rawson's original study had a 2 practice
(test-restudy vs restudy-only) × 3 final-test-format design, six groups,
n = 118. The project tested the single comparison of *mediator* recall between
test-restudy and restudy-only within the one final-test format that asks for cue,
mediator and target (the "cmr" format). In the original that comparison was
n = 36, mediator recall 34% (restudy-only) versus 51% (test-restudy),
`t(34) = 2.37`, `p = 0.0236` — a statistic the report notes was not printed in
the paper but supplied by the original authors; the standardized effect size was
`r = 0.377`. Note what this is *not*: not the whole paper, not the mediator-
effectiveness argument's two components, and not the vocabulary-retention headline
— one t-test on one of six cells.

**Stage 1: it did not replicate.** Powered to detect 75% of the original effect
(target n = 132), the first collection got 132 Wharton subjects and found
mediator recall 54.55% (test-restudy) versus 48.39% (restudy-only), a difference
of 6.16% in the original direction but not significant: `t(130) = 1.7119`,
`p = 0.0893`. A manual re-coding that forgave typos moved it only to
`p = 0.1141`. Both fail the pre-registered `p < 0.05`.

**Stage 2: pooled, it replicated.** The protocol then triggered a second
collection of 174 more subjects, total n = 306. Pooled, mediator recall was
53.53% versus 47.57%, `t(304) = 2.6404`, `p = 0.0087` — significant, same
direction. The typo-tolerant manual coding agreed (`p = 0.0124`). The report's
Discussion states the conclusion plainly: "the original result did not replicate
in the first round of data collection (p = 0.0893), but did replicate in the
first and second rounds of data collection pooled (p = 0.0087)."

**Deviations the report records.** The replication ran at the Wharton behavioral
lab (2016-17) rather than Kent State (2009); summer recruitment meant it included
some graduate as well as undergraduate students; and it used only the two cmr-
format conditions of the original six. The typo re-coding was an unplanned
robustness check the authors added after noticing exact-string matching could
misclassify recalls.

**For this base.** This is a first-significant-effect replication of one cell of
a six-cell design, and it required the larger stage-2 sample to clear the bar —
a materially weaker outcome than the Karpicke & Blunt result, which cleared at
stage 1. It says nothing about the mediator-effectiveness hypothesis's
mechanism, which was not what the tested comparison isolated.
