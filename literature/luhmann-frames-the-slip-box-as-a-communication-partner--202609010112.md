Luhmann presents his slip box not as a filing aid but as a second party he
communicates with. The argument starts from a claim about thinking itself:
sophisticated, connectable thought is impossible without writing, and since
one must write anyway, the notes can be organized so as "to create in the
system of notes a competent partner o[f] communication" (sec. I; the bracket
corrects a typo in the published translation). Communication, for Luhmann,
requires that the partners be able to surprise each other — information only
arises when a message is compared against other possibilities — so a note
collection that merely returns what was put in does not qualify (sec. I).

The structural choice that makes surprise possible is deliberately
anti-systematic (sec. II): instead of ordering slips by topic, every slip gets
a fixed number that never changes. Fixed placement allows arbitrary internal
branching (a slip 57/12 continued by 57/13 or supplemented by 57/12a), dense
cross-referencing between slips, and a keyword register as the entry point for
rediscovery. Out of long use of this technique "a kind of secondary memory
will arise, an alter ego with who we can constantly communicate" — a body of
notes with no hierarchy or linear structure, which "gets its own life,
independent of its author" (sec. II). Luhmann is explicit that no note has
privileged standing: "Every note is only an element which receives its quality
only from the network of links and back-links within the system," and an
unconnected note "will get lost in the card file" (sec. II).

Independence has a price paid in time (sec. III): "The slip box needs a number
of years in order to reach critical mass. Until then, it functions as a mere
container from which we can retrieve what we put in." Past that threshold the
box returns more than was stored — it "provides combinatorial possibilities
which were never planned, never preconceived" — because a query activates
internal relations the author could not trace in advance (sec. III). Section
IV defends the role of accident in this: like mutation in biological
evolution, the productive accidents are themselves produced by a complex
order, so order in research "results only from a combination of disorder and
order."
